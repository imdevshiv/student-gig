# 🎓 Student Gig Platform

A **Spring Boot** based monolithic web application that connects students with freelance gigs, internships, and short-term job opportunities.

## 🚀 Features

- 🧑‍🎓 Student registration & profile management  
- 🧑‍💼 Company/employer registration  
- 📄 Gig posting & search functionality  
- 📬 Application tracking system  
- 🔐 JWT-based Authentication & Authorization  
- 🗂️ Role-based access (Student, Employer, Admin)  
- 📁 Resume/document uploads  
- 🔍 Smart search and filters for gigs

## 🛠️ Tech Stack

- **Backend:** Java, Spring Boot, Spring Security, Spring Data JPA  
- **Database:** MySQL  
- **Authentication:** JWT  
- **Build Tool:** Maven  
- **API Tool:** Postman
